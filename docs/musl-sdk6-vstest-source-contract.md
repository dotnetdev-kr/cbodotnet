# SDK6 VSTest original source and translations

The isolated SDK6 source contract reads the full VSTest Git tree
`cc7fb0593127e24f55ce016fb3ac85b5b2857fec` (tree
`64a7abaa0abbf25f525e52f7e3086931c2b59743`). It pins fourteen original
build, project, packaging, license and notice files and verifies every tracked
source byte against that full Git baseline. The compiler evidence gate must
first bind all 304 own package members, including three reference assemblies,
to actual compiler commands. Six original imported dependencies keep their
separate component provenance.

The original source-build graph targets Core VSTest on `net6.0`, with the
genuine development version `17.0.3-dev`. This Linux CLI does not provide the
publisher's Full/Mono .NET Framework test hosts or closed coverage binaries.
The verifier binds all nine original source commands and their logs, the
source-build binlog, and the two exact emitted packages. Four narrowly derived
staging files substitute the original nuspec framework/version placeholders and
forward the original branch/commit properties. The original Git files and C#
framework declarations stay intact. Both packages retain their original
license; only CLI includes the notice, as its original nuspec declares.

All 234 original XLF files are converted to readable RESX inputs across thirteen
cultures. The source contract independently repeats the conversion from the
archived original XLF and neutral RESX bytes, checks every target and the exact
generated bytes, and verifies the separate `vstest-generated` source-tree role.
Every shipped resource-only satellite is decoded without loading an assembly.
Its strings must equal the original targets belonging to its actual compiler
output's source project and culture. The actual two-package layout contains
273 satellites and 299 embedded resource tables, using 208 distinct generated
RESX inputs. The remaining original resource inputs stay archived; they do not
become shipping-product compilation claims.

The retained private component proof is
`.build/sdk6-vstest-source-contract-review-v1/actual-compiler-original-resources-review-v1.json`.
The complete isolated source round trip at
`.build/sdk6-vstest-source-contract-fullpack-v1/results.json` covers 3,126 files,
passes the frozen source packer/verifier, and validates the source contract.
Four actual forgery controls reject a changed Git pin, a relabeled generated
source role, a self-asserted target receipt, and an edited translation even
after recomputing its package and PE fingerprints. Six focused tests cover
exact original targets, missing inputs, English substitution, edited generated
bytes, XML entities and the bounded staging adaptations.

These are corresponding-source and resource checks. The isolated round trip
does not establish the full normal producer, the final SDK6 native version,
two-CPU validation, source admission, or release qualification. Those gates
remain separate and closed.
