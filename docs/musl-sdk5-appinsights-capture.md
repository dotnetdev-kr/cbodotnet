# Retained SDK5 normal App consumption data

`musl_legacy5_appinsights_capture.capture` is an explicit collection helper. It
first executes the strict actual normal supplier/SDK consumption validator with
a mandatory normal context. It then retains the actual cache package/member,
original NuGet sidecars, feed package and all four Copy edges from both original
SDK/redist processes. Original logical paths, including the original double
slash in one installer path, remain unchanged. Equal whole bytes are stored once.

Raw sidecar fingerprints are new capture observations; their parsed metadata
and content hash must match the preceding validator's observations. Existing
compiler/replay/final/toolset descriptors bind their already retained files.
The destination must be separate from every existing source and input root.

Every candidate is read into bounded immutable buffers. All522 finite private
inputs and exact exclusion bodies are authenticated around the scan. Complete
candidate bytes and nested package members pass private-reference exclusion
before the first destination write. Publication uses those same buffers, with
exclusive ordinary0644 data files; compiler/preferred-source modes are separate.

`validate_data` checks the closed data inventory, logical mappings, package,
product, sidecar and Copy consistency. It reads the bounded unique original
NPK DLL member and requires its complete fingerprints to equal the captured
DLL, even if package metadata and sidecar hashes were rebound together.
It walks the complete central directory and verifies its true bounded entry
count before allocating ZIP entries, rejecting forged small counts and unsafe
or truncated directory entries.
Its saved normal result does not prove
normal execution independently. It reports archived construction, independent
normal replay, full source closure and admission as false. Future A5 must run
the actual archive-backed App/BOOT/normal/SDK validation again.

Tests use tiny task-derived fixtures and patched supplier boundaries; they do
not establish an actual new normal SDK5 producer or successful source archive.
This module does not activate production collection, sealing or publication.
