# SDK5 genuine App normal Docker adapter

`musl_legacy5_appinsights_normal.py` is an explicit additive adapter around the
unchanged genuine App5 worker and the pinned strengthened validator. It never
selects a container backend from ambient evidence. The original private entry,
worker, policy, API decoder and prior evidence remain unchanged.

The adapter builds a closed context from the authenticated producer record,
actual prepared identity, native CPU/RID, run/build/project identity, non-root
UID/GID and physical producer roots. It requires a separate fresh attempt at
`delivery/reports/build/appinsights`, the original App commit at
`workspace/work/appinsights`, and bootstrap5/6 at their original input paths.
Worker-critical orchestration bytes must equal the clean actual Git commit.
Full preferred-source namespace validation remains a separate source-packet
gate; a clean checkout alone does not close it.

`input_inventory` verifies original437 source files, the original reference
ZIP's70 selected members/65 DLL identities plus base FrameworkList XML, Mono
Portable targets/license, comparison-only original package and two frozen
Reader sources. It estimates the typed copy size without copying or executing.
`prepare_normal` requires the actual source and a new physical destination,
uses the immutable typed preparation recipe, rejects special entries/modes and
records complete input bytes/modes. It cannot prepare over a private attempt.

The exact Docker argv uses `sudo -n -- docker`, network none, read-only root,
one non-root user, all capabilities dropped, no-new-privileges, a bounded tmpfs,
the closed original environment and seven exact narrow mounts. Inputs,
bootstraps and orchestration are read-only; output/home/diagnostics are the new
attempt's writable roots. The unchanged observed-command wrapper captures real
process security and exit status. Complete argv equality rejects alternate
engines, extra/shadow mounts, image/user/environment changes and hidden flags.
The normal engine reports and original default AppArmor/seccomp checks remain
mandatory. Private Podman evidence cannot satisfy this entry.
Before any shared engine/security reader runs, the adapter checks both engine
JSON reports and every inspected Docker stage's process-status/AppArmor/exit
files as bounded ordinary regular files, with no symlink or special mode bits.
This preflight applies before execution, after the actual worker, and during
retained validation; FIFO evidence rejects before a blocking read.

`execute_normal` records one actual producer command and distinct normal
invocation/result/source-substage records, preserving failures without retries.
Packaging can validate the successful App substage before the rest of SDK
build finishes; the final normal `validate` entry additionally requires the
same command exactly once in the actual successful parent SDK build stage.
Validation checks full input preservation, all four complete ordered App,
Reader-build and replay argv, successful exits and full log fingerprints. It
binds the actual Reader executable to each original binary log and requires
distinct status/task/binlog content. The original strengthened compiler guard
checks actual App Csc sources, references, options, generated metadata and
public-only DelaySign behavior. The original Reader compiler proof remains
required. API comparison uses the unchanged decoder without writing error
artifacts during validation.

Only then may a new five-member local PCL NPK be constructed from actual
DLL/PDB/XML, the original source license and source-derived nuspec. The receipt
binds the actual source execution, strict API, every member and whole archive.
The adapter never substitutes a private NPK or invokes the old private verifier
to authenticate Docker records. The SDK feed/property/cache/Csc/Copy/toolset/
Crossgen consumer guard remains a separate integration step.

Current evidence is limited to small complete normal-envelope/process fixtures
and read-only original input checks. A real normal Docker App/Reader execution,
archive-backed normal validation and genuine SDK consumption are pending.
The current WSL host has no Docker CLI, and no Podman result is relabeled.
No original v8 byte or failure is changed; no new App or whole SDK build is
authorized by importing or validating this module.

The original Profile7 reference ZIP has no embedded license. Retaining the full
typed tree in a published source packet would redistribute that binary ZIP,
even though the local five-member App NPK excludes it. Separate Mono source
notices do not establish ZIP license coverage or historical PCL C#/IL preferred
source. Complete target/provider/import evidence and those source/license
roles remain open. All whole-producer, qualification and admission flags stay
false.
