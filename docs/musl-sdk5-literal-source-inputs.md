# SDK5 template, reference and Arcade source inputs

The distinct SDK5 policy and validator cover the five remaining original
template/reference/build-package roles without changing their raw artifact
kinds, package repository metadata or unresolved emitter observations.

The two complete template packages contain no PE code. Their 45 readable
template files correspond to the original TestTemplates commit and NUnit's
original v1.8.1 tag, including explicitly recorded publisher package line
endings. NUnit's nuspec still has no repository element. Its original license
URL and the complete tagged source and license are retained separately.

NETStandard.Library2.0.1 retains its description and all 113 assembly-embedded
`b7f182415927d3b98445d043e1680c56b9d1f17c` identities and the complete matching
publisher source/project recipe. NETStandard.Library.Ref2.1.0 retains its
original CoreSetup description commit, the actual declared standard source,
and the complete source-build-assets preferred IL. All121 assemblies and
24,959 method bodies/MVIDs correspond to that original IL. This is preferred
IL attribution; it does not claim a local compilation or recovery of the
historical compiler invocation.

The validator requires17 complete Git source roots, nine exact original or
canonical packages and a distinct data root. It rechecks every source tree,
original Git blob and actual archive/index mode, every fixed package member,
the original installer copy recipes and all derived correspondences. The
existing installer guard must validate all440 original files and six exact
patches; only its two GenerateLayout patches are reversed to read that
original copy recipe. No compiler worktree is rewritten or exempted.

The caller must first authenticate the complete used-source packet with the
unchanged source Packer. This component proof does not establish actual
producer package/Copy consumption, native bootstrap closure, a successful
normal producer, either CPU's qualification, or release availability. Raw
unknown observations remain intact for the admission layer to reconcile.
